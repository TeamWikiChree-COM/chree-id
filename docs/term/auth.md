# 用語: 認証

| 語 | コード上の名前 | 意味 |
| --- | --- | --- |
| パスワード | `password` | 通常のパスワードログイン |
| マジックリンク (メールログイン) | `magic_link` | メールで届くリンクを開いてログインする |
| TOTP (2段階認証) | `totp` | 認証アプリの6桁のコード。パスワードなどの2段階目に使う |
| 復旧コード | `recovery_code` | TOTP の端末を失くしたときに使う使い捨てのコード |
| パスキー | `passkey` | WebAuthn による認証。移行・統合・分離で移せない (認証器に user handle が焼き込まれているため) |
| 外部IdP | `oauth` | Google や GitHub でのログイン。ChreeID はこのとき RP (ログインしに行く側) になる |
| 信頼した端末 | trusted device | 2段階目を通したうえで本人が信頼した端末。次から2段階目を省く |
| ログインセッション | login session | ログイン中の端末ごとの記録。設定画面から個別に切れる |
| 認証の成立判定 | `AuthenticationPolicy` | すべての認証経路が通る判定。拡張できないようにしている |
