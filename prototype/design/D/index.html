C から変えたところ
  • 入力欄を MUI の TextField にした。 切り欠き付きのフローティングラベル、フォーカスで枠が primary の2px、 helperText は 12px で左に 14px 食い込む。MUI が素で出す形をそのまま写しています。
  • 設定を上部タブにした。A案のタブが良かったので。サイドナビ版も残してあります。
  • カードを枠線で囲った。A案の境目を採用。見出しの縦バーで塊の始まりを示し、枠で終わりを見せます。 ダークで境目が消える問題もこれで起きません。
  • 「メールでログイン」を「マジックリンク」に。前者は何が起きるか読めないので。
  • ログイン方法をアイコンだけにして、ツールチップを付けた。 GitHub も並べてあります。ただし下記の但し書きあり。
  • ダークの境目を直した。下記。
  • ログインのサービス名を黒にした。アイコンの隣に青字が並ぶと主張が強いので。
ダークテーマの直し

DokuFarm のダークは面 #0a0a0a / ページ背景 #0d0d0d で、 コントラスト比が 1.02:1、つまり実質同じ色でした。向こうはカードに枠線があるので成立していますが、 枠を外す B・C・D では境目が消えます。面を持ち上げ、ページを沈め、枠を面よりはっきり明るくしました。

  • 面 vs ページ 1.02:1 → 1.14:1（ModParks のダークは 1.17〜1.22:1）
  • 枠 vs 面 1.46:1 ／ 枠 vs ページ 1.66:1
  • ダークのときだけカードに 1px の枠を戻す

この直しは共通の style.css に入れたので、A・B・C も同時に改善されています。

アイコンだけにする件

依頼どおりログインカードは4つともアイコンだけにし、ModParks と同じくツールチップを付けました。 ただ ログイン画面 に並べて置いたとおり、 Google と GitHub はマークだけで通じますが、パスキーとマジックリンクは事情が違います。 前者はブランドの記号なので見れば分かりますが、後者は動作の名前で、 指紋や封筒の絵から「パスキー」「マジックリンク」を当てるのは初見では無理があります。

ツールチップは触れないと出ないので、初見の人には届きません。触る前に何ができるか分からない状態は ログイン画面では特に困ります。外部アカウントだけアイコン、動作はラベル付きを勧めます。 ログイン画面に両方置いたので、見比べて決めてください。

MUI との対応
  • 入力欄
    <TextField variant="outlined" size="small" />
  • トグル
    WikiChree の switch。MUI の Switch とは別物なので自前コンポーネントになります
  • タブ
    <Tabs> ＋ Inertia のリンク
  • 通知
    <Alert severity="..." />
  • ラベル
    <Chip size="small" />
  • ツールチップ
    <Tooltip title="...">。ModParks がソーシャルログインで使っているのと同じ
  • 見出しの縦バー
    sx の ::before。MUI の外なので theme に入れます
