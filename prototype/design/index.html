ChreeID デザイン案

色とレイアウトの寸法は DokuFarm、装飾とボタンの質感は ModParks、トグルは WikiChree の switch を土台にしています。 3案とも同じ style.css を共有し、違いは a.css / b.css / c.css だけです。

A案

DokuFarm 準拠 ／ 枠で囲う

DokuFarm にほぼ揃える。3サービスを行き来したとき一番違和感がない。設定は上部タブ。

B案

ModParks 寄り ／ 線で区切る

角丸4px、カードの枠なし。軽く見える代わりに、まとまりは余白頼りになる。設定は左サイドナビ。

C案

おまかせ ／ 見出しで区切る

枠でも線でもなく見出しで塊を示す。ヘッダーは半透明+blur で追従。角丸6px。

D案

C + A のタブ ／ MUI で出せる形

C の骨格に A のタブ。入力欄を MUI の TextField に合わせ、ダークの境目も直した。ページごとに分けてあります。
判断の材料
色は既に揃っている
DokuFarm の --color-primary と ModParks legacy の primary はどちらも #2563eb でした。3案とも色は共通で、違うのは区切り方だけです。
ダークテーマが同時に入る
DokuFarm のトークンをそのまま使うので、data-theme="dark" の一式が最初から付いてきます。右上の「ダーク切替」で確認できます。
設定画面の再構成
今は /profile と /security に分かれていて、どちらに何があるか名前から分かりません。/settings にまとめ、「プロフィール / セキュリティ / 接続サービス / 表示」に分ける案を各ページに入れてあります。A は上部タブ、B と C は左サイドナビです。
ダークテーマの境目
DokuFarm のダークは面とページ背景のコントラストが 1.02:1 で、枠線が無いと段差が見えませんでした。面を上げ・背景を下げ・枠を明るくして直してあります（4案すべてに反映済み）。
ログインカード
ModParks に倣って1枚のカードに寄せています。A はアイコンを活かして縦積み、B は画像を使わずサービス名を大きく出す ModParks そのまま、C はその中間です。
